Work

Three years, three very different problem shapes

  1. A voice-first parenting assistant going up against Huckleberry and Riley. I own the voice stack and the product surface it feeds.

    • Architected a multi-model routing system and the real-time voice pipeline — streaming transcription, interruption handling, conversational state — on LiveKit, Deepgram, Cartesia and ElevenLabs.
    • Engineered a persistent memory layer so the assistant recalls parent preferences and child routines across sessions instead of restarting cold every call.
    • Built a RAG-powered lactation support assistant — retrieval pipelines over a curated clinical knowledge base, wired into live conversational flows.
    • Shipped automated evaluation pipelines with Langfuse and custom observability across 30+ agent tools, turning "it felt off" into a regression you can point at.
    • Automated the GitHub release pipeline and OTA updates for the React Native app: 14-day release cycles down to 3.

    React NativeNode.jsPythonGCPLiveKitDeepgramCartesiaElevenLabsLangfuse

  2. Employee one. I set the product architecture and infrastructure direction, then went out and deployed it inside customers' environments.

    • Built an end-to-end voice-agent simulation and evaluation framework: automated red-teaming, adversarial prompts, interruption detection, tone analysis and adherence scoring.
    • Developed VoiceAssist, a configurable LiveKit platform letting customers deploy embeddable voice widgets with their own prompts and knowledge bases.
    • Integrated Twilio, SIP trunking and PSTN so agents place and take real phone calls — not just tidy web sessions.
    • Built templatized, industry-specific agent architectures and self-serve deployment tooling: kickoff to go-live in about a week, down from multi-week.
    • Created Gatekeeper, an open-source framework shielding widgets and outbound agents from spam, abuse and malicious traffic.
    • Worked as a forward-deployed engineer, embedded with partner teams building production voice agents.

    • Led peak-season scalability work: Booking API p95 latency −45%, error rate −79%, and $5K/month off AWS RDS through database optimisation.
    • Built a refund fraud prevention system on DBT insights, encrypted payment identifiers and rule-based workflows — ₹5L/month in abuse stopped.

About

A conversation breaks in the gaps. Two hundred milliseconds of silence and a person starts wondering whether the thing is still there.

Most of my work lives in those gaps. I started at Urban Company shaving latency off booking APIs that millions of people hit during peak season, moved to SuperBryn as engineer #1 building voice agents that had to survive real phone lines, and now lead AI engineering at Coddle AI, where the user is a parent holding a baby at 3am and has exactly one hand free.

The through-line is the unglamorous half of AI: routing, memory, observability, evaluation. Anyone can demo an agent. Making one behave the same way on Tuesday as it did on Friday is the actual job — which is why I build the harness before I build the agent.

I studied Electronics & Communications at IIIT Delhi. Outside work I train MMA and boxing, which is a surprisingly good school for shipping software: you find out fast which of your ideas survive contact.
